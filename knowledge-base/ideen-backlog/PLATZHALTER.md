# Platzhalter — `ideen-backlog/`

Dieser Ordner nimmt **Ideen ohne aktuellen Auftrag** auf, je Idee ein Dokument mit
Datumspräfix. Er ist noch leer; die Datei hält ihn in Git und ist bewusst **nicht**
indexpflichtig (sie trägt kein Wissen, nur Struktur — testerzwungene Ausnahme).

**Abgrenzung:** Eine Idee ist **kein** Bauplan — keine Arbeitspakete, keine Abnahmekriterien,
keine Testfälle. Sobald sie die hat, gehört sie nach `grundwissen/`.

**Lebenszyklus:** Wird eine Idee beauftragt, entsteht ein Bauplan in `grundwissen/`, der auf
sie **verweist**; die Idee selbst bleibt stehen und wird weder verschoben noch gelöscht — sie
ist die Herkunft, der Plan ist die Arbeit. Sobald die erste Idee hier liegt, wird diese Datei
gelöscht.

`ssot-grundgeruest.md.vorlage`).*
